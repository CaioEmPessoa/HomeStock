# HomeStock
A stock control web-application written in nodeJS/MariaDB with the intended use for really organized people, and also a project for me to study nodejs.

# Features
As of now, you will host this app in a machine on your local network and can:
- Register new products
- Register new entries of thoose products on your home
- Edit, delete and view thoose products and inventory items.
*This is rather limited since I started this project so recently, but it served me a lot of in terms of studing the javascript language.

# Plans
In the future I want to add some cool features that would make this project really unique, aside from just a CRUD. Thoose features are:
- Bar code scanner that automatically adds a new product to the listing.
- Email/Notification system to alert when something is getting close to the expire date. Also when a product runs out and it has a minimum registered on the system.
- Mass creation of new entries, so you can just dump out a bunch of itens after retruning from the groceries
- More options for the front-end in order to add compatibility with various older devices.
